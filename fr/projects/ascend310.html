Architecture Double Moteur d'Inférence

Implémente deux chemins d'inférence parallèles, démontrant la solution complète de l'inférence logicielle pure à l'inférence accélérée par matériel :

MindSpore Lite (CPU)

Utilise @kit.MindSporeLiteKit pour charger le modèle .ms
Entrée modèle : 640x640x3 float32
Inférence CPU 2 threads
Prétraitement complet (RGBA vers float + normalisation) et post-traitement (NMS, IoU) en ArkTS

CANN ACL (NPU)

Charge dynamiquement libacl_runtime.so via dlopen
Gestion complète ACL : Init → SetDevice → CreateContext → CreateStream
Utilise aclmdlLoadFromFile pour charger le modèle .om
aclrtMalloc pour mémoire NPU, aclrtMemcpy pour transfert de données
API NAPI C++ : initYoloEngine / runYoloInference

1. Sélection d'Image

PhotoViewPicker → Redimensionner à 640x640 + letterbox padding

2. Prétraitement

RGBA vers float32 normalisation → Entrée dans le moteur d'inférence

3. Inférence NPU/CPU

Inférence NPU CANN ACL ou inférence CPU MindSpore Lite

4. Post-traitement

NMS suppression non-maximale + calcul IoU → Filtrer les résultats

5. Affichage Résultats

Canvas rendu boîtes de détection → Disposition trois colonnes avec statistiques
