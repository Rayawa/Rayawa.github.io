复扫雷 ComplexSweeper

基于青月晓原作的三端原生复扫雷：圆复数与闵可夫斯基两种模式、彩色／黑白外观，以及 HarmonyOS、Android 和 Apple 平台的统一公开源码。

GitHub 仓库三个平台，同一套规则

两种模式，两套线索

圆复数 · 24 种显示值

四种雷为 +1、−1、+i、−i。邻域和为 a+bi 时显示 √(a²+b²)，+1 与 −i 得到 √2。展开要求旗数匹配，实虚比例与真实比例相同或互为倒数。

闵可夫斯基 · 39 种显示值

双曲单位 j² = +1，四种雷为 +1、−1、+j、−j。邻域和为 a+bj 时显示 √(a²−b²)，负值以虚数形式显示。严格展开要求旗数匹配，且实部与 j 部的绝对值分别相等。

0 不等于没有雷

两种模式都可能因抵消显示 0；双曲模式中 +1 与 +j 也会给出 0。只有周围完全无雷的空白格才会自动扩散，翻开所有非雷格即可获胜。

触屏轻点切换旗型，长按 400 ms 翻开并清除该格标记；连片展开仍跳过其他带标记格。macOS 左键翻开、右键标记或展开数字。首击九宫格安全；三档难度为 9×9 / 10 雷、16×16 / 40 雷、30×16 / 99 雷。

三个平台，同一套规则

HarmonyOS、Android 与 Apple 工程集中在同一仓库，分别使用 ArkTS / ArkUI、Kotlin / Compose、Swift / SwiftUI。三端使用整数规则与相同种子指纹验证一致性；原生界面、音频与触感由各平台独立实现。
