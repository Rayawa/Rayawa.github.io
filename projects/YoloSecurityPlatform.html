智能安防远程监控平台

一个贯通视觉识别、规则判断、数据存储、实时推送与人工处置的全栈安防系统。平台既能手动分析图片，也能持续扫描图片与视频目录，以 YOLOv5 识别结果触发业务告警，并将状态变化实时同步到 Web 与 HarmonyOS 终端。

GitHub 仓库 查看系统链路

项目速览

这是一个把目标检测转化为可处置告警的全栈安防平台。图片上传、视频抽帧或目录扫描进入 YOLO 推理，再由业务规则生成告警；Spring Boot、MySQL 与 WebSocket 负责状态保存和实时同步，Web 与 HarmonyOS 端用于复核和处置。项目强调证据归档、告警状态流转和识别结果的可追溯性。

  • 识别到处置模型类别映射为业务告警并进入处置状态机。
  • 现场证据检测框图片和视频帧随告警记录保存。
  • 多端同步事务落库后广播更新，供管理端与移动端查看。

用途与使用

用途

用于远程监控场景中的图片与视频识别，把模型检测、业务告警、人员处置和证据归档串成可追踪流程。

使用方式

上传图片或视频并查看识别结果；告警到达后在管理端查看实时消息、核对证据并更新处置状态。HarmonyOS 客户端提供移动端访问与分享入口。

技术与实现

FastAPI 承载 YOLOv5 推理，Spring Boot 3.3 处理规则和业务接口，MySQL 8 保存记录，WebSocket 推送告警；Vue 与 ArkTS/ArkWeb 构建界面。

成果与边界

页面展示识别截图、告警旅程与多端结构。具体检测效果应结合数据集、阈值和部署环境判断。

从识别到处置的告警闭环

从“模型看见了什么”到“安保人员完成处置”，每一步都保留业务状态与现场证据。

图片与视频识别

支持网络图片、文件上传与视频抽帧；视频最多抽取 5 帧逐帧检测，并生成汇总告警。

YOLO 双模型推理

以 COCO 与烟火检测模型覆盖人员、车辆、物品、动物、烟雾和火焰等现场对象。

业务规则映射

把模型类别转换为烟火异常、人员聚集、人员闯入、车辆异常、动物进入与物品异常。

实时告警广播

数据库事务提交后再通过 WebSocket 广播，避免页面收到尚未落盘的短暂状态。

处置状态机

告警按照“待处置 → 处置中 → 已关闭”流转，并阻止对已关闭记录进行重复操作。

证据归档

自动保存检测框图片与视频帧拼接图；目录识别完成后将源文件归档至 processed。

一次告警的完整旅程

浏览器主动提交与 ai-watch 自动扫描共享同一条后端业务链路。

01 · Input

现场输入

图片 URL、上传文件，或模拟摄像头目录中的图片与视频。

02 · Vision

FastAPI + YOLO

完成推理、检测框绘制与多帧对象汇总。

03 · Rules

Spring Boot

规则映射、状态校验、事务控制与接口编排。

04 · Data

MySQL 8

设备、告警、处置状态和现场图片持久化。

05 · Delivery

WebSocket

把新告警与状态变化广播到在线管理终端。

识别结果可追溯

管理端呈现实时运营状态，AI 输出保留检测框，便于复核模型判断。

HarmonyOS 客户端

客户端结合 WebView、设备侧感知与 HarmonyOS 分享能力，支持移动端处置。

ArkTS + ArkWeb

输入局域网平台地址即可连接；客户端包含加载进度、返回导航与演示账户自动登录。

智感握持

根据左右手握持状态调整悬浮功能按钮位置，让单手操作更自然。

HarmonyShare

支持碰一碰分享与隔空抓取，将受控演示会话快速传递到附近设备。

技术栈

前端、业务后端、AI 服务、数据库与设备端协同组成完整工程。
