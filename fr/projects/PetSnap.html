HarmonyOS et Ascend

PetSnap · Classification chat / chien

PetSnap est une application HarmonyOS native de classification chat/chien avec MindSpore Lite : galerie ou appareil photo, inférence CPU MobileNetV2 locale et apparence claire / sombre.

HarmonyOS · Dépôt GitHub

De l’entraînement à une application native

Origine du modèle

L’expérience MindSpore / MobileNetV2 fige le réseau principal et affine la tête de classification sur Kaggle Cats vs Dogs. Ses étapes d’entraînement et de conversion sont documentées séparément du client HarmonyOS actuel.

Inférence locale

Le modèle pet.ms d’environ 2 Mo est intégré à l’application. Les images sont redimensionnées à 224×224 et traitées sur CPU en FP32 par MindSpore Lite, sans classification dans le cloud.

Galerie et appareil photo

Choisir une image de galerie ou prendre une photo affiche un résultat chat/chien. ArkUI et HdsNavigation proposent une interface native claire ou sombre.

Périmètre d’utilisation

Classification binaire

Le modèle distingue chats et chiens, sans reconnaître les races. Sous 70 % de confiance, l’interface indique une image hors catégorie ; ce seuil ne garantit pas le rejet de tous les autres objets.

Notes de développement

L’entraînement suit une expérience de classification chat/chien avec MindSpore / MobileNetV2. Le dépôt public contient le client HarmonyOS, le prétraitement et le chargement du modèle.
