一套程序管好租车门店

围绕真实门店运营的四段横向能力线，让每台车的去向、每位客户的记录和每一分租金都清清楚楚。

01 · 档案管理

车辆与客户井井有条

车牌、品牌、车型、日租金、押金与客户驾照、身份证信息一站建档；录入时自动检查重复证件与车牌。

02 · 借还计费

自动算清每一笔账

租车自动筛出可用车并打印凭条；退车按实际日期与闰年计算天数，超期双倍计费、押金全额退还。

03 · 检索筛选

一秒定位历史记录

支持按品牌、车型、颜色、状态或日期区间精确筛选，也能输一个关键字跨表模糊匹配车辆与客户。

04 · 图表报表

命令行里的直观统计

自动绘制 ASCII 柱状图呈现品牌、驾龄与月度走势，支持口令保护、操作日志与一键导出文本报表。

本地文件分布与链表实现

作为数据结构大作业，项目刻意绕开了 STL 容器，直接用裸指针单向链表与五类物理文件完成全部持久化和统计。

vehicle.dat 车辆主档 定长 struct 二进制块
renter.dat 客户档案 定长 struct 二进制块
rent.dat 租借订单 定长 struct 二进制块
pwd.dat 登录口令 XOR 异或加密存储
log.txt 操作审计 纯文本追加记录

手写链表与单翻译单元组织

车辆（VehicleNode）、租客（RenterNode）和订单（RentNode）三条链表全部由 new / delete 动态管理，启动时按结构体块还原，退出时写回。

main.cpp 引入核心实现 car_rent.cpp，再按业务顺序拼接 menu1 至 menu7 七个子模块，配合 .clangd 配置保持良好的代码补全体验。

// 无图形库条件下按最大值比例缩放绘制 ASCII 柱状图
void drawBarChart(char labels[][32], int values[], int n) {
    int mx = 0;
    for (int i = 0; i < n; i++)
        if (values[i] > mx) mx = values[i];
    for (int i = 0; i < n; i++) {
        printf("  %-10s [%3d] ", labels[i], values[i]);
        int bar = mx > 0 ? values[i] * 30 / mx : 0;
        for (int j = 0; j < bar; j++) printf("#");
        printf("\n");
    }
}
