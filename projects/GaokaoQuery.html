高考成绩便捷查询工具

把逐个手动查询录取结果的重复劳动做成一条批处理流程：脚本读取名单表格，自动查询、核对并整理，最后导出成一份完整的成绩表。

项目速览

工具面向批量查询场景。它使用 Playwright 驱动浏览器访问北京教育考试院的录取结果查询接口，逐条获取结果，用 pandas 整理数据结构，再通过 openpyxl 写出 Excel 文件。过程中会核对姓名是否匹配，并对没有结果、专业为空等情况分别记录，最后输出一份可核对的汇总表。

  • 批量而非逐条从表格读取名单，一次性完成全部查询，省去重复的手工操作。
  • 结果可核对对姓名不匹配、无查询结果、专业为空等情况分别标记，便于人工复核。
  • 自动准备依赖首次运行时自动检查并安装 pandas、playwright、openpyxl 等依赖。

关于这个项目

它要解决什么

录取结果查询需要逐个输入信息、逐个记录，条目一多就很容易出错或遗漏。这个工具把查询、校验与整理合并成一步。

怎么运行的

脚本先确认依赖是否齐全，缺失则自动安装；随后读取待查询名单，用 Playwright 驱动浏览器调用查询接口，逐条获取结果并记录；最后汇总写出 Excel。每条结果都会与名单中的姓名核对，不一致的单独标出。

用到什么

Python 编写；浏览器自动化使用 Playwright；数据处理使用 pandas；表格导出使用 openpyxl。

边界

工具面向批量整理场景，查询结果以官方接口返回为准；网络异常或接口变动时需要人工确认。个人信息仅在本机处理，不对外传输。

工作流程

从读取名单到输出表格，四个步骤依次执行。

检查并准备依赖

首次运行时检测 pandas、playwright、openpyxl 是否可用，缺少则自动安装，避免环境问题中断流程。

读取待查询名单

从表格载入需要查询的条目，作为整批处理的输入。

逐条查询并核对

驱动浏览器调用查询接口获取结果，并与名单中的姓名逐条比对，不一致的记录单独标记。

整理并导出

用 pandas 整理结果结构，再由 openpyxl 写出 Excel 汇总表，便于直接查看与复核。

异常分别记录

没有查询结果、录取专业为空等情况不会被静默丢弃，而是分别归类记录。

数据留在本机

全部处理在本地完成，名单与结果不会上传到任何第三方服务。
