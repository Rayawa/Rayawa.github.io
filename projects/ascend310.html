双推理引擎架构

实现了两套并行的推理路径，充分展示从纯软件推理到硬件加速推理的完整方案：

MindSpore Lite (CPU推理)

使用 @kit.MindSporeLiteKit 加载 .ms 格式模型文件
模型输入: 640x640x3 float32
2线程 CPU 推理
完整的预处理（RGBA转float + 归一化）和后处理（NMS、IoU）在 ArkTS 侧实现

CANN ACL (NPU推理)

通过 dlopen 动态加载 libacl_runtime.so
完整的 ACL 设备管理：Init → SetDevice → CreateContext → CreateStream
使用 aclmdlLoadFromFile 加载 .om 离线模型
aclrtMalloc 分配 NPU 设备内存，aclrtMemcpy 数据搬运
C++ NAPI 层暴露 initYoloEngine / runYoloInference 两个接口

① 选择图片

PhotoViewPicker 选图 → 缩放到 640x640 + letterbox padding

② 预处理

RGBA 转 float32 归一化 → 输入推理引擎

③ NPU/CPU 推理

CANN ACL NPU 推理 或 MindSpore Lite CPU 推理

④ 后处理

NMS 非极大值抑制 + IoU 计算 → 过滤检测结果

⑤ 显示结果

Canvas 绘制检测框 → 三栏布局显示统计图例与检测记录
