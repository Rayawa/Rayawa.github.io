端侧精准还原训练表现的秘密

模型训练基于 MindSpore 2.0.0 冻结主干微调分类头。为了保证迁移到手机后不掉精度，端侧代码严格对齐了像素通道与归一化参数。

像素通道顺序对齐

HarmonyOS 的 PixelMap 读出的是 RGBA 四字节数组，而训练阶段使用 OpenCV 按 BGR 三通道读图并应用 ImageNet 均值与方差。预处理阶段先剥离 Alpha 通道并反序填入 BGR，再送入模型推理。

状态指示与防误触

底部指示灯实时反馈模型加载状态，推理期间叠加轻柔遮罩避免重复提交。

ets/pages/ModelPredictor.ets 
// 与训练时 config.py 对齐的通道重排与标准化
const MEANS = [0.485, 0.456, 0.406];
const STDS  = [0.229, 0.224, 0.225];

let index = 0;
for (let i = 0; i < pixels.length; i += 4) {
  if (index >= float32Data.length) break;
  // pixels = [R, G, B, A] → 模型输入要求 BGR
  float32Data[index]     = (pixels[i + 2] / 255.0 - MEANS[2]) / STDS[2];
  float32Data[index + 1] = (pixels[i + 1] / 255.0 - MEANS[1]) / STDS[1];
  float32Data[index + 2] = (pixels[i]     / 255.0 - MEANS[0]) / STDS[0];
  index += 3;
}
说明：二分类实验应用，只区分猫和狗，不支持品种细分；70% 门槛属于基础的置信度提示策略，不能保证排除所有其他对象。桌面训练实验记录与当前公开的 HarmonyOS 客户端仓库分开维护。
