模块一 · 红绿灯板开发

聚焦 GPIO 输出与按键输入协同，构建从基础电平点亮到多线程任务调度与按键消抖联动的完整实验链路。

硬件配置与学习路径

  • 三色 LED：GPIO_10 红灯，GPIO_11 绿灯，GPIO_12 黄灯
  • 控制按键：GPIO_8，S3 功能按钮

学习顺序：light.c → traffic.c → ability.c → button.c → control.c

开发文件清单

  1. light.c：基础灯控，单灯开关与组合状态点亮
  2. traffic.c：标准交通灯时序循环与任务调度
  3. ability.c：多线程并发控制与任务同步
  4. button.c：按键状态检测、消抖处理与事件捕获
  5. control.c：按钮干预红绿灯切换综合实验

模块二 · 炫彩灯板开发

结合声音波形、PWM 调光与红外/光照环境感知，搭建从单一器件驱动到多传感器场景联动的实验序列。

硬件配置与学习路径

  • 三色 LED：PWM1 红色，PWM2 绿色，PWM3 黄色
  • 无源蜂鸣器：PWM0 音频驱动
  • 人体红外传感器：ADC 通道 3
  • 光敏电阻：ADC 输入（环境亮度判定）

学习顺序：beep.c → music.c → led.c → human_sensor.c → photosensitive.c → human_sensor_light.c

开发文件清单

  1. beep.c：蜂鸣器占空比与频率发声控制
  2. music.c：音符编码旋律播放与节拍控制
  3. led.c：音乐播放同步驱动三色 RGB 律动
  4. human_sensor.c：人体红外热释电信号 ADC 采样
  5. photosensitive.c：光敏电阻ADC采样与昼夜阈值判断
  6. human_sensor_light.c：夜间暗光环境下人体感应自动亮灯

模块三 · 环境监测板开发

面向多传感器总线复用与 OLED 图形渲染：实现 I²C 总线共享下的温湿度采集、可燃气体 ADC 监测及超阈值报警。

硬件配置与技术特性

  • MQ-2 燃气传感器：ADC 通道 5，可燃气体浓度数字化采样
  • AHT20 温湿度传感器：I²C 接口高精度温湿度读取
  • OLED 显示屏：SSD1306，I²C 总线复用与周期画面刷新
  • 火焰传感器与蜂鸣器：监测参数超限时触发声光报警

开发文件清单

  1. mq2_demo.c：MQ-2 可燃气体浓度 ADC 采样演示
  2. aht20.c / .h：AHT20 温湿度传感器底层驱动
  3. aht20_demo.c：周期采集温度与相对湿度输出
  4. oled_ssd1306.c / .h：SSD1306 字库与显存刷新驱动
  5. oled_demo.c：OLED 文本与图形界面渲染测试
  6. enrionment_demo.c：多传感融合监测与超限联动告警

模块四 · AT 指令开发

在 OpenHarmony AT（HiAT）框架基础上注册自定义串口命令，打通上位机指令下发、参数校验与格式化回传闭环。

自定义计算指令

cal.c 注册并实现自定义串口指令 AT+CALC=a,b：接收两个整型参数后完成参数合法性检验与除零保护，依次计算和、差、积、商四项运算结果并通过串口规范回传。

UART Serial · 115200 8N1 
> 输入指令
AT+CALC=12,3

< 返回结果
+CALC:Sum=15
+CALC:Diff=9
+CALC:Prod=36
+CALC:Quot=4
OK

编译、烧录与技术栈

基于 OpenHarmony GN/Ninja 构建系统、CMSIS-RTOS2 与 HiBurn 工具完成固件构建与串口调试。

01 激活目标模块 编辑根目录 rayawa/BUILD.gn 启用对应实验模块，再进入模块内 BUILD.gn 指定需参与编译的具体 .c 源码文件。
02 全量构建与烧录 在 OpenHarmony 源码根目录运行 hb build（GN + Ninja）生成固件镜像，使用 HiBurn 工具烧录至 Hi3861 开发板。
03 串口日志观测 打开串口调试终端，通信参数配置为 115200, 8N1，观察芯片启动状态、传感器读数或交互验证自定义 AT 指令回包。
