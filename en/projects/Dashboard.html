Dashboard · App Market

A HarmonyOS market-data project in collaboration with Shenjack, with native browsing, filters, charts, app details and system sharing for public app and atomic-service information.

From market overview to an individual app

Market changes

Browse app and atomic-service counts, SDK and rating distributions, API history and rankings enabled by the backend. Visible data depends on server configuration.

Search and compare

Find apps by name, package, App ID or shared link; browse filtered, sorted and paginated lists, details, screenshots and trends. Exact fields and features depend on the client.

Native pages and web access

Business browsing uses native platform pages; S Station and external documents keep web entry points. HarmonyOS, Apple and Android adapt navigation, windows and system capabilities separately.

Client progress

HarmonyOS · 3.2.0

ArkTS / ArkUI client, targeting API 26 with API 20 minimum. Version 3.2.0 adds review rankings with report windows, sample thresholds and sorting, and improves details, charts, paged search and caching. System sharing and cross-device continuation remain available.

Apple · 3.1.0

SwiftUI / Swift Charts for iPhone, iPad and macOS. Native lists, combined search, details and charts use the shared API, NavigationSplitView, system sharing and offline caching.

Android · In development

A Kotlin / Jetpack Compose client with home, app lists, search and details. Requires Android 12 (API 31) or later; still in development.

Data and collaboration

Shared backend

Clients use harmony_get_market /api/v0. Shenjack’s contribution to data collection and backend collaboration remains credited; this page focuses on Rayawa’s native client work.

Cache and freshness

HarmonyOS and Apple can fall back to older cache on network failure and show its time. Public market information is for reference and may be incomplete, outdated or inaccurate; each client has its own privacy policy.
