HarmonyOS Cosplay · Offline · HarmonyOS

ElvaCos · Cosplay Planner

An offline-first, native HarmonyOS app for cosplayers. Link characters and cosplay plans with preparation, packing, events, photos and expenses, so scattered notes become part of one plan.

GitHub repository

From inspiration to photos

Characters and plans

Collect characters and variants, then make a plan for each cosplay. Preparation templates, custom tasks and deadlines track progress; task completion, equipment availability and packing confirmation are separate states.

Wardrobe and events

Reuse equipment across plans and build packing lists for each one. Events can be tentative, single-day or multi-day, with list and calendar views, linked plans and an optional device-calendar entry.

Photos and references

Import selected images through the system photo picker. Organise references and finished work, filter and batch-update processing states; the portfolio shows final and published photos.

Actual expenses

Record individual payments and compare them with budgets by plan or category. View category totals and six-month trends; reusing wardrobe items does not automatically create a new expense.

How it works

Getting started

Create a character and a plan, list tasks and equipment, then link an event. Confirm packing before leaving, organise photos afterwards and record payments.

Local data

Core functions work on the device. Metadata uses an encrypted RDB and images live in the app sandbox. Metadata and system backups are supported; the metadata JSON itself does not include photos.

Navigation and themes

Home, Cos, Events, Wardrobe and Me use native navigation and forms. Five colour palettes work with light, dark or system appearance.

Current status

Version 1.0.0-beta.1 has a beta package signed with a development profile; it has not been released to the app marketplace. Core offline functions are implemented. Real Huawei account login has not passed acceptance testing, cloud sync is not implemented and team records are currently local.
