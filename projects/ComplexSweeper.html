四种雷，24 种可达数值，一套不同于经典扫雷的推理规则。基于青月晓的开源原作，把圆复数模式移植到 HarmonyOS、Android 与 Apple 平台，以原生界面保留经典像素观感。

扫雷，但雷是复数

+1−1+i−i

四种雷

正实雷、负实雷、正虚雷、负虚雷分别为 +1、−1、+i、−i。格子上的数是周围所有雷相加后所得复数的模长。

抵消不是空白

周围一颗 +1 和一颗 −i，显示 √2；+1 与 −1 相互抵消，显示 0。空白表示周围完全没有雷，0 则可能藏着抵消对。

胜利与展开

翻开所有非雷格即胜利。展开需要邻域旗帜数量与真实雷数相同，且实虚比例符合真实比例或其倒数；旗帜保护被标记的格子。

手机轻点未翻开格子切换旗型，长按翻开；macOS 左键翻开、右键标记。点击已翻开的数字格尝试展开，点击人脸重开。三档难度：9×9 / 10 雷、16×16 / 40 雷、30×16 / 99 雷。

三个平台，同一套规则

HarmonyOS

ArkTS + ArkUI，原生导航与棋盘、像素贴图、音效、触觉反馈和本地战绩。

GitHub 仓库

Android

Kotlin + Jetpack Compose，原生棋盘与经典计雷器，使用 SoundPool、触觉反馈和 SharedPreferences。

源码尚未公开

Apple

Swift + SwiftUI，单一多平台工程覆盖 iOS、iPadOS 与 macOS；触屏与鼠标分别适配操作。

源码尚未公开

三个移植版使用全整数运算与 mulberry32 随机数，并用相同种子的棋盘指纹检查规则一致性。只移植圆复数模式，未移植上游的双曲复数模式。

原作与移植

原作由青月晓（Yueqing-Chen）以 Zig + Win32 开发，规则、图集与音效来自其开源项目；Rayawa 负责这三个平台的原生移植。移植基于上游 v1.2.0，代码按 GPL-3.0 发布。经典扫雷原始图像属于 Microsoft，其他新增素材与音效来自上游，具体授权见各仓库的素材说明。
