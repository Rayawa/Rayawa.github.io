高考录取结果查询工具

把反复复制准考证号、网页点查询再抄进表格的枯燥流程，交给一个省心稳妥的小助手。自动读入 Excel 名单、拉起可见浏览器配合人工确认，核对姓名无误后安稳写回每条录取去向。

Python Playwright pandas openpyxl Excel 批量回写 断点续查与备份
历史归档（私有仓库）

一条稳妥的数据流转链

采用“浏览器人工可见 + 读写全自动”的半自动策略，直接把表格字段约束和备份安全嵌进三个工作阶段里。

输入阶段

Excel 名单读取

从主表格读入待查名单，支持跳过已查记录、指定行号续跑或重查异常条目。

准考证号 考生号 姓名
查询阶段

可见浏览器协同核对

使用有头 Chromium 提交查询，遇图形验证码人工随手接管；抓回结果先比对姓名防串行，并细标“暂无结果 / 专业为空 / 不匹配”。

Playwright Chromium 防串行核对
落盘阶段

安全回写与双重备份

按周期写回工作簿并生成即时 .bak 与时间戳历史快照，断网中断也不丢进度。

录取院校 专业 / 批次 查询状态

实用贴心的细节与运行环境

既考虑到官网页面随时可能弹窗需要人工配合，也尽量把容错、依赖安装与历史归档全部打包妥当。

名单自动续跑，中断也不用重来

支持跳过已成功条目、从任意指定行号续跑，或者单独针对此前空白与失败的记录再跑一轮，大批名单也能分次从容查完。

可见浏览器协作，人工随时可接管

保留有头 Chromium 界面而非盲目硬爬，一旦官方入口出现图形验证或临时弹窗，人工随手点过即可继续自动推进。

边查边存盘，运行前后双重备份

启动前后自动留下即时备份与带时间戳的历史快照，查询过程中亦定期落盘保存，哪怕突然断网也不会丢失前功。

GaokaoQuery/ — 运行方式与目录 
# 历史运行环境初始化
$ python3 -m venv .venv && source .venv/bin/activate
$ python -m pip install -r requirements.txt
$ python -m playwright install chromium
$ python main.py

GaokaoQuery/
├── main.py             # 依赖自检、交互菜单、查询与写回主控
├── output.xlsx         # 输入名单与结果回写主表
├── output.xlsx.bak     # 运行前后自动生成的即时备份
├── backups/            # 带时间戳的历史 Excel 快照
├── logs/               # 本机运行日志
└── debug/              # 异常页面调试截图
说明：查询时需向官方查询站点提交考生信息，名单、结果表格、备份与日志均保存于本机。项目现已作为历史工具归档，源码中的页面选择器按当年站点结构编写，恢复使用前须先核对入口变化。
