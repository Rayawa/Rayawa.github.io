鸿蒙 Place + Visit · Local · HarmonyOS

Loci 地点记忆

以 Place + Visit 为核心的 HarmonyOS 本地个人空间记忆应用。一个地点拥有稳定的身份，每次到访留下独立的文字、心情与时间，让熟悉的地方逐渐积累自己的故事。

GitHub 仓库

一个地点，多次到访

Place · 地点

一个稳定的地点身份，承载坐标、地点信息与到访历史。再次来到这里，仍然关联同一个 Place。

Visit · 到访

每次到访创建独立记录，保存当时的文字、Mood 与日期。补记或重访不会覆盖此前的记忆。

当前实现与后续方向

地点历史与筛选

文字、心情、地点历史与筛选已实现，地点与到访记录通过本地数据库关联保存。

数据与界面分层

ArkUI V2 界面通过 ViewModel 与 Repository 访问数据，地点身份、坐标与日期规则集中在领域层。

先完成地点记忆

首轮围绕选点、记录、重访与恢复推进。照片、视频、录音、旅程 Trip、轨迹 Track 和 Atlas 均为后续方向。

当前进展

项目仍在开发。地点数据、ViewModel 与偏好存储已有 API 26 真机测试，导航与设置已做基础验收；真实地图与定位、首次落旗、界面保存及重启恢复的完整流程仍待验收，当前依赖 Loci 的 Map Kit 应用配置。不能将已有数据库验证视为地图闭环完成。
