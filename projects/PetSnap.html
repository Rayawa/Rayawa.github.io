PetSnap · 猫狗分类

PetSnap 是使用 MindSpore Lite 的 HarmonyOS 原生猫狗分类应用：相册或拍照输入，MobileNetV2 在 CPU 本地推理，支持深浅色界面。

HarmonyOS · GitHub 仓库 MindSpore / MobileNetV2

从训练实验到原生应用

模型来源

训练与转换流程沿用 MindSpore / MobileNetV2 猫狗分类实验：冻结主干、微调分类头，数据来自 Kaggle Cats vs Dogs。原实验记录与当前 HarmonyOS 客户端分开维护。

本地推理

应用内置约 2 MB 的 pet.ms 模型，输入缩放为 224×224，在 MindSpore Lite CPU 路径上以 FP32 推理，不依赖云端分类服务。

相册与拍照

用户选择相册图片或拍照后查看猫／狗分类结果；ArkUI 与 HdsNavigation 提供原生界面，并跟随深浅色模式。

使用边界

二分类实验

只区分猫和狗，不提供品种识别。低于 70% 置信度时界面提示非猫狗图片；这只是置信度阈值策略，不能保证排除所有其他对象。

开发与复现

训练侧说明见原实验仓库；HarmonyOS 侧包含模型封装、预处理与原生页面。设备兼容性和识别效果应结合实际构建与样本验证。
