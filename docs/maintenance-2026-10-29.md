# 2026-10-29 项目内容更新

本次对照电脑 Develop 和 SSD Develop 中的项目 README、实际页面与配置更新网站。GitHub 可见性通过已连接账户的仓库元数据核实。中、英、法三版同步，个人介绍、摄影、生活及联系方式保留原文。

## 项目变化

- **时迹 / Loci**：由地点记忆扩展为每日时间记录。介绍多行输入、跨夜与重叠时间、作息、列表与周视图、分类统计，保留地点与到访功能。首页和详情改用仓库现有的前景、背景图层，页脚同步名称。原有 URL 保留。
- **ElvaCos / 绮秀**：按 1.0.0-beta.1 的实际功能整理计划、衣柜、活动、照片与实际支出。精简重复使用步骤，保留本地存储和备份说明。账号登录未成功验证、云同步未实现；体验重构文档仍是计划，没有写成已发布功能。
- **Dashboard**：鸿蒙版更新至 3.2.0，补充口碑榜、报告窗口、样本门槛及加载优化；Apple 仍为 3.1.0，Android 仍在开发。
- **TextVideoGen**：介绍本地视频工作区和制作工具，合并重复的环境、交付及打包宣传。保留 13 阶段流程、历史样例与常用指令，明确仍由 OpenCode Agent / Skills 执行，独立生产 API 未实现。
- **GaokaoQuery**：名称改为录取结果查询，补充历史归档状态，不再暗示当前入口已经验证；纠正“信息不会对外传输”的旧说法，说明查询需要向官方站点提交相应信息，表格与日志在本地保存。未读取或复制历史个人数据表、日志、调试截图。
- **其他项目**：AstraPlusCar、启智01、CarRent、CommChain 与安防页移除重复的“项目速览 / 关于项目”，保留具体技术内容。课程项目直接说明用途，减少全栈、闭环、保证跨机器一致等泛化表述。首页项目摘要相应缩短。

主要依据为 Loci、ElvaCos、Dashboard 三端、ComplexSweeper、TextVideoGen、AstraPlusCar 两端，以及 SSD 中的 SmartShed、启智01、PetSnap、WeakSignal、手势识别、安防与课程项目文档。Loci 另核对 ui/pages 与数据结构；Dashboard 鸿蒙版核对 docs/i18n/README_zh.md，Android 核对 Gradle 配置；小车恢复机制核对 Index.ets 中的三次重试及间隔。
