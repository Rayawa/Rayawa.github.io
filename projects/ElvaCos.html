鸿蒙 Cosplay · Offline · HarmonyOS

绮秀 ElvaCos

HarmonyOS 原生、离线优先的 Coser 个人管理应用。从角色灵感与 Cos 计划，到准备、打包、活动、照片和花费，让零散的记录围绕同一个计划串起来。

GitHub 仓库

从灵感到出片

角色与计划

收集角色与版本，为每次出 Cos 建立计划。用准备模板、自定义任务与截止日期安排进度，分别记录准备完成、装备可用和装包确认。

衣柜与活动

装备可以在不同计划间复用，打包清单跟随计划。活动支持待定、单日与多日，提供列表与月历，并可关联计划或添加到设备日历。

照片与参考

通过系统照片选择器导入图片，归档参考图与作品；支持筛选、多选和批量更新处理状态，作品集展示最终作品与已发布照片。

实际花费

逐笔记录付款，按计划或分类对比预算，查看分类统计与近半年趋势。复用已有装备不会自动计成一次新的实际支出。

用途与使用

怎样开始

新建角色和计划，列出准备任务与所需装备，关联活动日期；出发前确认装包，活动后整理照片并记录实际付款。

数据留在哪里

核心业务在本机完成，元数据存入加密 RDB，图片保存在应用沙箱。支持元数据备份与系统备份；元数据 JSON 本身不包含照片。

界面与外观

首页、Cos、活动、衣柜、我的五个入口，配合原生导航与表单。提供五组主题配色和浅色、深色、跟随系统模式。

当前进展

当前为 1.0.0-beta.1，已有使用开发调试签名的 Beta 测试包，尚未作为应用市场正式版本发行。核心离线业务已实现；华为账号真实登录尚未验收成功，云同步未实现，团队记录目前保存在本机。
