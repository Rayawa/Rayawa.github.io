Sweet Potato Mod

农业与魔法的完美结合！与@teddyxlandlee协作开发的Minecraft模组项目，添加了地瓜、农林台、研磨器、魔法锅、附魔作物等。

项目速览

Sweet Potato Mod 是与 Featurehouse 团队协作开发的 Minecraft 模组，围绕地瓜这一作物扩展出完整的种植、加工与附魔链路。模组新增紫薯、红薯、白薯三个品类及其衍生材料，提供研磨器用于加工，并以魔法锅实现作物转换与附魔；附魔树苗与附魔作物进一步改变了原有的生长机制。

  • 农业玩法扩展紫薯、红薯、白薯三个品类与地瓜粉等衍生材料构成内容基础。
  • 加工与魔法链路研磨器承担加工，魔法锅经灵魂火激活后实现转换与附魔。
  • 团队协作项目由 Featurehouse 团队维护，作者、贡献者与问题反馈入口均已列出。

关于这个模组

它要解决什么

原版 Minecraft 的农业玩法在收获后即告结束，作物缺少后续用途。该模组将地瓜扩展为一条持续加工的链路，使种植与合成、附魔产生关联。

玩法内容

地瓜分为紫薯、红薯、白薯三类，可加工为地瓜粉等材料。研磨器将地瓜研磨为地瓜粉；魔法锅需在其下方 3×3 区域点燃灵魂火激活，可将三个任意品类的生地瓜转换为其他品类或随机附魔。附魔树苗与附魔作物的生长速度快于原版对应作物。

模组内容清单

新增方块四种：魔法锅、研磨器、农林台与附魔树叶。新增物品五种：地瓜、地瓜粉、地瓜皮、附魔树苗与附魔作物。另生成一种结构「附魔树」。当前版本为 1.5.1，历史版本可在团队 Wiki 的版本页查阅。

用到什么

模组基于 Minecraft Fabric 与 Java 开发，新增的作物、方块与配方由模组代码与资源文件共同定义。运行需要 Fabric Loader 与 Fabric API。

如何获取

模组可通过 Featurehouse 下载页获取，具体玩法参见团队 Wiki，问题与建议提交至 GitHub Issues。支持的 Minecraft 版本与依赖要求以下载页说明为准。

新的内容

地瓜

在本模组中添加的类食物。它分为紫薯、红薯和白薯，以及三个变种，有地瓜粉、地瓜皮等。

魔法锅

魔法锅散发着黑色的光泽。你可以通过在它下方3×3区域内点燃灵魂火来激活魔法锅，将三个任意品类的生地瓜转换为其他品类或对其进行随机附魔。

研磨器

研磨器有着一个磨盘，它的作用是将地瓜研磨为地瓜粉。

附魔树苗和作物

附魔树苗和作物的生长速度要快于原版树苗或作物，且会长成附魔树或附魔作物。
