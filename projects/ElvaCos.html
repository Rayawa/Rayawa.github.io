鸿蒙 Cosplay · Offline · HarmonyOS

绮秀 ElvaCos

给 Coser 用的 HarmonyOS 个人管理应用。准备一个角色时，可以一起整理任务、服装道具、活动日期、参考图和花费，数据保存在本机。

GitHub 仓库

准备一次出 Cos

角色与计划

为角色的不同版本建立计划，列出准备任务和截止日期。任务完成、装备备齐和装包确认分开记录。

衣柜与活动

服装和道具可以重复用于多个计划。活动有列表和月历，也可以关联计划或添加到系统日历。

照片与参考图

从系统相册选择图片，按角色和计划整理参考图与成片，支持筛选、多选及处理状态标记。

花费与预算

逐笔记下实际付款，按计划或分类查看支出和半年趋势。衣柜里的标价不会自动算进实际花费。

数据与界面

使用首页、Cos、活动、衣柜、我的五个入口，提供五组配色和深浅色模式。文字记录存入加密数据库，照片存入应用私有目录。可导出元数据备份，但导出的 JSON 不包含照片。

当前版本

1.0.0-beta.1，目前用于 Beta 测试，尚未在应用市场正式发行。核心功能可离线使用；华为账号登录尚未验证成功，云同步未实现，团队信息也只保存在本机。
