HarmonyOS Place + Visit · Local · HarmonyOS

Loci · Place Memories

A local HarmonyOS personal memory app built around Place + Visit. A place keeps a stable identity while every visit has its own writing, mood and date, gradually giving familiar locations a personal history.

GitHub repository

One place, many visits

Place

A stable place identity holds coordinates, place information and visit history. Returning to the same location links to the same Place.

Visit

Each visit is a separate record with its own writing, mood and date. Returning or adding an earlier visit does not overwrite previous memories.

Implemented features and next steps

History and filters

Writing, moods, place history and filters are implemented. A local database stores the relationships between places and visits.

Data and interface

ArkUI V2 views access data through ViewModels and Repositories. Place identity, coordinate and date rules live in the domain layer.

Start with place memories

The first phase focuses on selecting places, recording, revisiting and restoring them. Photos, videos, audio, Trip, Track and Atlas are future work.

Current status

Still in development. Place data, ViewModels and preference storage have API 26 device tests, and navigation and settings have basic acceptance checks. Live maps and location, first markers, saving through the interface and the complete restart flow still await validation and depend on the app’s Map Kit configuration. Database validation does not establish a complete map workflow.
