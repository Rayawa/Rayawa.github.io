ElvaCos · Cosplay Planner

A personal HarmonyOS app for cosplayers. Keep tasks, costumes and props, event dates, references and expenses together for each cosplay plan. Records are stored on the device.

GitHub repository

Prepare a cosplay

Characters and plans

Create plans for different character variants, with tasks and deadlines. Task completion, available equipment and packed items are tracked separately.

Wardrobe and events

Reuse costumes and props across plans. Events have list and calendar views and can be linked to plans or added to the system calendar.

Photos and references

Select pictures from the system photo picker, organise references and finished photos, then filter, select several items or mark processing states.

Expenses and budgets

Record actual payments and view spending by plan or category, plus six-month trends. Wardrobe prices do not automatically become expenses.

Data and appearance

Home, Cos, Events, Wardrobe and Profile form the five tabs, with five palettes and light or dark appearance. Text records use an encrypted database; pictures live in private app storage. Exported metadata JSON does not include photos.

Current version

1.0.0-beta.1 is a Beta build, with no official app-store release yet. Core features work offline. Huawei sign-in has not been successfully verified; cloud sync is unimplemented and team information stays local.
