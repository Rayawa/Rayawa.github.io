Dual Inference Engine Architecture

Implements two parallel inference paths, showcasing the complete solution from pure software inference to hardware-accelerated inference:

MindSpore Lite (CPU)

Uses @kit.MindSporeLiteKit to load .ms format model
Model input: 640x640x3 float32
2-thread CPU inference
Complete preprocessing (RGBA to float + normalization) and postprocessing (NMS, IoU) implemented in ArkTS

CANN ACL (NPU)

Dynamically loads libacl_runtime.so via dlopen
Complete ACL device management: Init → SetDevice → CreateContext → CreateStream
Uses aclmdlLoadFromFile to load .om offline model
aclrtMalloc for NPU device memory, aclrtMemcpy for data transfer
C++ NAPI exposes initYoloEngine / runYoloInference APIs

1. Select Image

PhotoViewPicker → Resize to 640x640 + letterbox padding

2. Preprocessing

RGBA to float32 normalization → Feed into inference engine

3. NPU/CPU Inference

CANN ACL NPU inference or MindSpore Lite CPU inference

4. Postprocessing

NMS non-maximum suppression + IoU computation → Filter detection results

5. Display Results

Canvas rendering detection boxes → Three-column layout showing stats and detection records
