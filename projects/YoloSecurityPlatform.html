校园智能安防远程监控平台

实训课程中的校园安防监控项目。前端大屏与移动客户端实时联动：FastAPI 驱动 YOLOv5 识别图片与视频抽帧，Spring Boot 将检测结果转换为业务告警落盘至 MySQL，并通过 WebSocket 广播到 Web 与 HarmonyOS 终端进行追踪与处置。

查看系统界面 查看系统链路
Spring Boot 3.3 / Java 17 YOLOv5 / FastAPI Vue 3 / WebSocket ArkTS / ArkWeb MyBatis-Plus MySQL 8 OpenCV Docker Compose OpenAPI
5 管理端核心页面 · 6 类告警 · ≈ 2s 自动扫描 · 3 端协同

平台界面与识别证据

管理端包含由 Spring Boot 托管的监控大屏与账号登录界面；AI 推理服务输出的检测框图片与视频多帧拼接图会随告警一同存档，便于人工复核模型判断。

Web · OpenAPI · HarmonyOS
监控大屏汇总在线设备、待处置告警、告警总数与 AI 识别事件，下方为 WebSocket 自动刷新的实时告警流，每条均带有识别类别与置信度。

告警如何传递

浏览器手动上传检测与 ai-watch 约 2 秒一轮的目录自动扫描共享同一条后端业务链路，确保数据落盘与推送顺序严格一致。

01 · Input 现场输入图片 URL、上传或目录监控
02 · FastAPI + YOLO视觉推理、画框与多帧汇总
03 · Spring Boot规则映射、状态校验与事务
04 · MySQL 8设备、告警与证据图像落盘
05 · WebSocket向在线 Web 与移动终端广播

告警核心能力

从“视觉模型识别出了什么”到“安保人员处置关闭工单”，全流程保留状态校验与现场图像证据。

图片与视频抽帧识别

同时兼容网络图片 URL、本地文件上传与视频分析；视频上传后最多均匀抽取 5 帧逐帧送检，并生成汇总告警记录。

YOLO 双模型协同推理

联动 COCO 通用模型与烟火专用检测模型，覆盖现场人员、车辆、物品、动物以及烟雾和火焰等多种异常目标。

六类业务规则映射

依据业务配置将原始检测类别转换为烟火异常、人员聚集、人员闯入、车辆异常、动物进入与物品异常六种标准化告警类型。

事务提交后广播

严格等待数据库事务成功提交后再触发 WebSocket 广播推送，避免在线看板收到尚未正式落盘的短暂脏状态。

告警处置状态机

工单严格按“待处置 → 处置中 → 已关闭”单向流转，后端拦截并阻止对已关闭记录发起的重复操作。

自动归档留证

自动保存标有检测框的图片与多帧拼接图作为历史核验证据；目录自动识别结束后，将源文件规范归档至 processed 目录。

HarmonyOS 客户端

移动客户端融合 ArkWeb 容器、设备端握持感知与鸿蒙分布式近场分享能力，满足日常巡检与演示需求。

01 ArkTS + ArkWeb 输入同一局域网的平台地址即可接入；内置加载进度指示、页内返回导航以及演示账户快捷自动登录。
02 智感握持适应 借助设备传感器识别左右手握持姿态，动态调整悬浮控制按钮布局位置，让单手查看和处理告警更自然。
03 HarmonyShare 支持碰一碰分享与隔空抓取交互，能够把当前受控的演示会话快速流转并传递至附近鸿蒙设备。
