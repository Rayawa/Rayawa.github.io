At a glance

This guide accompanies the Hi3861 embedded experiments. It organizes wiring, source files, and learning paths around traffic lights, colorful lighting, environmental sensing, and custom AT commands. Readers can begin with GPIO, PWM, and sensors, then progress to concurrent tasks and serial command extensions.

Purpose and use

Purpose

Use this as the reference manual for the Hi3861 experiment series, covering boards, peripherals, source layout, and learning order.

How to use it

Choose traffic lights, color LEDs, environmental sensing, or AT commands, then inspect the relevant pins, source files, and build steps. The complete README loads below and the original Markdown is linked above.

Technology and implementation

OpenHarmony on Hi3861, C, GPIO, PWM, ADC, I²C/OLED, and UART/AT commands underpin the experiments; each module uses a different group of peripherals.
