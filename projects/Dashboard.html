客户端进展

HarmonyOS · 3.2.0

ArkTS / ArkUI 原生客户端，目标 API 26、最低 API 20。3.2.0 新增口碑榜，可选报告窗口、样本门槛和排序；同时优化详情加载、图表、搜索分页和缓存。保留系统分享与跨设备接续。

Apple · 3.1.0

SwiftUI / Swift Charts 客户端覆盖 iPhone、iPad 与 macOS。原生列表、组合搜索、详情与图表，共用 API；使用 NavigationSplitView、系统分享和离线缓存。

Android · 开发中

Kotlin / Jetpack Compose 原生客户端，已有首页、应用列表、搜索和详情，最低 Android 12（API 31），仍在开发。

数据与协作

共同后端

看板由 Rayawa 与 Shenjack 协作开发。客户端使用 harmony_get_market 的 /api/v0 接口，复用 Shenjack 的市场数据后端，以各平台的原生界面展示。

缓存与数据时效

HarmonyOS 与 Apple 客户端在网络失败时可回退到旧缓存并提示时间。市场信息来自公开网络，仅供参考，不能保证完整、实时或准确；各端隐私处理以各自政策为准。
