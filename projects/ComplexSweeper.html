两种复数规则，双倍烧脑乐趣

地雷拆成四个方向分量后，数字不再只是“数个数”——连周围有 +1 和 −1 抵消的“0”，也得靠全局推理才能排掉。

z = a + bi  →  |z| = √(a² + b²)

圆复数模式（24 种显示值）

四种地雷对应 +1、−1、+i、−i。盘面会直接出现 √2、√5 等无理线索。想双击展开数字格，需要标旗数匹配且实虚比例与真实比例相同或互为倒数，推演感极强。

j² = +1  →  √(a² − b²)

闵可夫斯基模式（39 种显示值）

引入双曲单位 j² = +1 后，当 |a| < |b| 时格子里甚至会冒出 i、√3i 这样的虚数提示；而且只要 +1 撞上 +j，模长立刻归零！展开要求实部与 j 部的绝对值分别相等。

01 顺手的触屏与桌面操作 手机端轻点即可轮换四种雷旗，长按 400 ms 直接翻开并清掉标错的旗帜；macOS 桌面端完美承袭左键翻开、右键标旗与快速展开数字的经典习惯。
02 三档经典难度与独立战绩 涵盖初级 9×9（10 雷）、中级 16×16（40 雷）与高级 30×16（99 雷），首击九宫格保证安全；圆复数与闵可夫斯基各自记录最快用时与胜负场次。

多端原生支持

HarmonyOS、Android 与 Apple 三端源码已整合进同一仓库，采用统一整数规则与同种子交叉验证，保证各地雷生成与判定完全一致。

平台目录 开发语言与 UI 覆盖设备与特性
HarmonyOS ↗ ArkTS / ArkUI 原生触控标旗、长按清旗、独立战绩记录与触感/音效反馈。
Android ↗ Kotlin / Jetpack Compose 三档棋盘自适应与本地最快纪录存储。
Apple ↗ Swift / SwiftUI 覆盖 iPhone、iPad 与 macOS（Mac 端支持鼠标左右键经典操控）。
