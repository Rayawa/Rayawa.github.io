At a glance

This project organises OpenHarmony embedded exercises on the Hi3861 into four tracks: a traffic-light state machine, lighting with buzzer coordination, environmental data acquisition, and custom AT commands. Each track first implements control of a single peripheral, then combines it with other modules. Together the four scenarios cover input, processing and output.

  • Four tracksTraffic, lighting, environment and AT commands, progressing from single-point control to multi-task coordination.
  • Independently runnable scenariosEach track is a complete, demonstrable scenario whose result can be observed directly.
  • Source available for referenceEach track maps to its own program files, and the README can be read online.

About this project

What it addresses

A common situation in embedded learning is knowing each peripheral individually but lacking experience in organising them into a complete system. This project arranges GPIO, PWM, sensors and serial communication into a learning path of four independently runnable scenarios, ordered by difficulty.

What the four tracks contain

The traffic light uses a state machine to switch between signals and detect illegal horn use; the lighting track generates light effects through PWM and coordinates them with a buzzer; environmental monitoring samples temperature, humidity and light over ADC and I²C and displays them on an OLED; the AT command track extends the serial port into a customisable command interface.

What it uses

A Hi3861 development board with OpenHarmony LiteOS-M, developed in C, covering GPIO, PWM, ADC, I²C and an OLED display, as well as UART serial communication.

How to read it

Choose a board following the module order on this page, check the pin assignments and peripherals, then open the corresponding README for the source layout and build steps. A full README reading page is also provided; reproducing the physical results requires the matching board and components.
