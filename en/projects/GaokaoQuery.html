College Admission Result Query Tool

An earlier script for checking college admission results. It reads an Excel list, uses Playwright to query results, and writes institutions, majors, admission rounds and query status back to the sheet. The project is now archived.

Workflow

Read the list

Read query records from Excel, skip existing results, continue from a selected row or retry unsuccessful entries.

Query and compare

Use a browser to query admission results, compare names and record missing results, empty majors or mismatched information.

Save and back up

Write institutions, majors, rounds and query status to Excel, with periodic saves and backups before and after a run.

Where data is used

Queries send the required candidate information to the official query site. Lists, result sheets and logs are stored locally.

Archive status

This is a historical tool. The endpoint and page selectors have not been revalidated. They need checking before reuse; this page describes the earlier implementation.
