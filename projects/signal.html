基于光杠杆放大的微弱电信号测量系统
Design and Implementation of a Weak Electrical Signal Measurement System Based on Optical Lever Amplification

针对微弱电信号幅值低、易受噪声影响且难以直接测量的问题，设计了一套基于光杠杆转换放大的微弱电信号测量系统。系统通过"电信号—机械偏转—光学位移—数字输出"的多级转换链路，实现微弱电信号的间接检测与量化分析。

阅读完整论文 (PDF)

针对微弱电信号幅值低、易受噪声影响且难以直接测量的问题，本文设计了一套基于光杠杆转换放大的微弱电信号测量系统。系统通过接收线圈获取外部微弱电磁信号，利用载流线圈在恒定磁场中的电磁作用，将感应电流变化转换为机械偏转响应，并结合光杠杆结构与PSD传感器实现微小角位移的光学放大检测。通过信号调理、模数转换和嵌入式数据处理实现信号采集与量化分析，同时利用专用标定模块建立输入电流与PSD输出之间的对应关系。本文对系统结构、工作原理及误差来源进行了分析，并提出实验验证方案。

关键词：微弱电信号；光杠杆；电磁转换；PSD传感器；嵌入式数据处理

§2 系统总体设计

模块化架构与多级转换链路

本系统以长方体框架作为整体机械支撑结构，采用模块化设计思想，将整个装置划分为四大功能模块。装置框架长度方向作为信号转换与光学检测的主要路径：左侧安装悬吊式偏转结构，右侧布置激光发射、光斑位置检测以及数据处理电路。信号接收模块与偏转模块采用一体化线圈结构，由同一根连续铜线绕制形成。微弱电信号发生模块位于装置外部，用于产生可控微弱电信号。为降低环境干扰，装置整体采用电磁屏蔽结构，数据处理部分采用金属屏蔽罩进行隔离。

§3 微弱电信号发生模块

稳定可控的测试信号源

电路设计与实现

计算机音频调制 + Si4713 射频发射

微弱电信号发生模块主要由计算机音频输出接口、Arduino控制单元以及Si4713射频发射芯片组成。计算机负责生成幅值和频率可控的低频调制信号，通过3.5mm音频接口输入Si4713的LIN与RIN音频输入端；Arduino通过I2C通信接口对Si4713进行初始化和参数配置。Si4713内部集成频率合成、调制控制以及射频输出功能，可将输入音频信号调制到指定射频载波上并通过天线输出。

程序设计与实现

信号生成与射频发射控制

低频调制信号由计算机音频输出产生（Python脚本生成正弦波），Arduino负责完成与Si4713之间的通信控制。程序通过I2C总线完成Si4713初始化，利用 setTXpower() 设置射频输出功率，通过 radio.tuneFM() 配置载波发射频率。相较于传统数字波形生成方式，该方案利用计算机音频输出实现高稳定性的低频调制信号产生，并通过Si4713完成射频调制发射，提高了输入信号频率和幅值控制精度。

§4 信号接收模块

场电信号到电流信号的第一次转换

信号接收模块采用轻量化、可移动式结构设计，主要由接收线圈以及周围构建稳定磁场的永磁体组成。接收线圈采用多匝绕制结构以增大交变磁场变化时产生的感应电动势，线圈两侧布置磁极相对的钕铁硼强磁铁，使线圈所在区域形成方向稳定的磁场环境。

当外部微弱交变电流信号通过空间传播形成变化磁场时，接收线圈中的磁通量随时间发生变化，根据法拉第电磁感应定律产生感应电动势，并进一步形成感应电流。接收线圈产生的感应电流经过闭合回路传输至偏转线圈，为后续磁电转换过程提供驱动电流。

接收线圈与偏转线圈采用直接连接方式（一体化线圈结构），减少了连接过程中的信号损耗以及额外干扰，避免了传统分离式连接中接触电阻和连接稳定性对微弱信号传输造成的影响，提高了系统整体灵敏度。

§5 偏转模块

微弱信号物理放大的核心

偏转模块是系统实现微弱信号物理放大的核心部分，主要由悬吊式偏转线圈、永磁体、反射镜以及机械支撑结构组成。偏转线圈通过接收线圈的两根细铜丝悬挂于框架上，两侧是相对布置的钕铁硼永磁体。反射镜固定安装于偏转线圈上并随线圈同步转动，一束来自右侧的准直激光射向反射镜，反射回右侧的一维位置敏感传感器（PSD）上。

当接收线圈产生的感应电流 I 流经偏转线圈时，载流线圈在两侧永磁体产生的恒定磁场 B 中受到安培力作用，产生转动力矩。细丝同时产生恢复力矩，当安培力矩与恢复力矩平衡时，系统达到稳定偏转状态。根据反射定律，反射镜使反射激光产生 2θ 的角偏转，经过距离 D 最终照射在远端PSD感光面上。

I = (2kD / NB) · x   →   x ∝ I

在小角度偏转条件下（θ ≤ 5°），反射光斑位置与偏转线圈的电流之间满足近似线性关系。偏转模块实现了将微弱电流信号转换为可观测的光学位置信号，为后续数据处理模块对信号进行检测与量化提供了基础。

§6 数据处理模块

光学信号检测、数据转换与测量结果输出

6.1 数据计算原理

归一化位置算子 P — PSD采用双端输出结构，两路输出信号分别为 Ia 和 Ib。为消除激光功率波动、环境光变化以及器件增益差异的影响，引入归一化算子：

P = (Ib − Ia) / (Ia + Ib) −1 ≤ P ≤ 1

在系统工作范围内，归一化算子 P 与感应电流 I 之间满足近似线性关系：

I = C · P + b

其中 C 为转换系数，b 为系统零点修正项，通过标定实验获得。

信号频率 f — 通过连续采集PSD输出信号，计算归一化算子随时间变化的波形，利用过零检测方法确定周期位置：

f = 1 / T = 1 / (t2 − t1)

电动势幅值 U — 接收线圈与偏转线圈串联，系统等效阻抗由线圈电阻和电感参数共同决定。通过LCR数字电桥实测获得等效参数：

U = I · |Z| = I · √(R² + (2πfL)²)

6.2 电路设计与实现

PSD + AD8628 信号调理 + ADS1115 高精度采样 + Arduino

数据处理模块由PSD传感器、AD8628信号调理电路、ADS1115模数转换模块以及Arduino控制单元组成。PSD利用横向光电效应，根据光斑在感光区域上的能量分布变化产生两路差分光电流输出。AD8628构成跨阻放大电路进行电流电压转换（低输入偏置电流、低失调电压），ADS1115负责16位高精度模数转换，通过I2C接口与Arduino通信。

6.3 程序设计与实现

数据采集、归一化计算、数字滤波与参数转换

程序采用模块化设计，主要包括环境光补偿、数据转换、滑动平均滤波以及结果输出。环境光补偿用于降低背景光对PSD输出信号的影响；滑动平均滤波算法对归一化位置算子进行降噪处理，降低随机噪声对测量结果的影响。经过滤波后的数据用于光斑位置、电流、电压以及频率参数的计算。

§7 系统标定与量化模型

建立输入电流与PSD输出之间的定量转换关系

7.1 标定原理

为获得系统标定所需的准确输入量，在偏转线圈回路中串联已知阻值的精密采样电阻，通过测量采样电阻两端电压获得线圈实际电流：I = VR / Rs。标定过程中，Arduino输出不同占空比的PWM驱动信号，使偏转线圈中的工作电流逐步变化，采集多组 (Ii, Pi) 实验数据，通过最小二乘拟合求解转换系数 C 与系统零点偏移量 b。

7.2 标定模块电路

电流输出部分 + 转换系数计算部分

标定模块由电流输出部分和转换系数计算部分组成。电流输出部分负责为线圈提供可控且可测的标准输入电流；转换系数计算部分复用实际测量过程中的数据处理硬件（PSD + AD8628 + ADS1115 + Arduino），仅需更换Arduino运行程序即可实现标定与测量模式切换，保证了标定过程与实际测量过程具有相同的信号传输路径。

§8 误差分析

误差来源、不确定度评估与精度提升策略

误差来源

  • 磁场不均匀性：永磁体磁场空间分布非理想均匀，影响安培力与偏转角对应关系
  • 机械结构误差：悬吊铜线材料特性与安装状态影响等效扭转刚度；反射镜安装角度、激光入射方向微小变化被光学放大
  • 模拟电路误差：运放输入失调电压、偏置电流、温漂；反馈元件参数变化
  • ADC量化误差：参考电压波动、采样噪声限制系统分辨能力
  • 环境干扰：外部电磁干扰通过空间耦合或电源线路进入系统；温度变化造成长期漂移

不确定度评估模型

  • A类不确定度：多次重复测量统计分析，反映空气扰动、机械微振动、电路随机噪声等随机因素
  • B类不确定度：基于仪器精度和系统参数标定误差评估，含ADC采样精度、放大电路参数误差、转换系数不确定性
  • 合成标准不确定度：各独立误差分量按误差传播规律合成
  • 扩展不确定度：引入包含因子，表示一定置信概率下的误差范围

精度提升策略

硬件方面：提高机械结构稳定性（防风、优化支撑、增加屏蔽）；优化永磁体与线圈相对位置使磁场更均匀；缩短模拟信号传输路径。软件方面：滑动平均滤波、异常值剔除、合理选择采样参数。流程方面：建立规范化校准流程，实验前完成光路调整和零点校准，定期检查系统基准状态。

§9 应用案例与效果分析

典型实验场景验证系统检测能力

光电效应实验

将光电管输出端连接至系统输入端，使微弱光电流流经接收与偏转结构。保持入射光频率不变，改变光强度，记录光斑位置变化并计算对应电流值，验证系统对光电流变化的检测能力。

微弱光电信号检测

采用可调节光源产生不同强度光信号，逐步降低输入信号强度，记录PSD输出位置变化，确定系统在当前条件下的有效检测能力。同时长时间采集零输入状态数据，分析系统零点漂移和背景噪声水平。

材料光电特性测试

将待测光电材料置于稳定光源下，产生光生电流并接入测量系统。通过检测光斑位置变化，实现对不同材料输出电流的定量比较，分析其响应强度、稳定性及变化规律。

§10–11 局限性与展望

系统边界认知与未来优化方向

系统局限性

  • 灵敏度与响应速度矛盾：降低机械刚度提高灵敏度会牺牲动态响应范围
  • 有限线性范围：输入信号过大时光斑超出PSD有效检测区域
  • 频率响应受限：机械惯性限制，主要适用于低频或准静态微弱信号检测
  • 环境敏感：依赖实验室受控环境，空气流动、振动、温度变化均会产生扰动
  • 光路需校准：装置移动或重新安装后需重新校准光路

未来展望

  • 结构优化：优化悬线材料、降低运动部件质量、改进阻尼设计；增加防振防风结构
  • 磁场优化：提高工作区域磁场均匀性，改善电流与机械响应线性关系
  • 信号处理升级：采用更高性能嵌入式平台，引入更完善的数字滤波和自动校准算法
  • 模拟前端优化：降低放大电路噪声、温漂及ADC误差
  • 应用拓展：多通道接收结构、更高性能传感器，拓展至低照度光检测、弱电磁环境分析等方向
